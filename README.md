# Katalog PGNet

Katalog harga & stok ready **PGNet Computer** untuk dibuka di HP:
Processor · RAM · SSD · Others Parts, lengkap dengan pencarian dan keranjang.

- Tampilan: `index.html` (GitHub Pages)
- Data: Google Apps Script membaca tab **Database** di file *Katalog PGNet* (`?format=json`)
- Data diperbarui tiap 5 menit dan disimpan di browser supaya cepat dibuka.

## Isi repo
| File | Fungsi |
|---|---|
| `index.html` | tampilan katalog |
| `config.js` | link Web App Apps Script (`APPS_SCRIPT_URL`) |
| `manifest.json` | nama, warna & ikon saat dipasang di layar utama HP |
| `sw.js` | service worker: tampilan tersimpan di HP (cepat & tetap buka saat offline) |
| `ikon-192.png`, `ikon-512.png`, `ikon-maskable-512.png`, `apple-touch-icon.png` | ikon aplikasi |
